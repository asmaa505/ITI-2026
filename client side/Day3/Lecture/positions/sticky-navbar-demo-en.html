What's happening?

This navbar has position: sticky; top: 0;. From the start, it scrolls normally with the page (just like relative). But as soon as it reaches the top of the screen (top: 0), it "sticks" and stays fixed in place (just like fixed) — but only while you're still scrolling inside its parent container.

The core CSS (no JS needed)

The sticking behavior itself works with pure CSS:

.navbar { position: sticky; top: 0; z-index: 100; }

sticky vs fixed — quick comparison

position: fixed sticks to the viewport immediately from page load, and is removed from the normal flow entirely (its original space collapses).
position: sticky stays part of the normal flow until it hits a threshold (top: 0 here), and only then behaves like fixed — bounded by its parent.

Common gotcha

sticky needs an explicit top (or bottom/left/right) value to work at all. Also, if any parent element has overflow: hidden or overflow: auto, sticky will silently stop working — this is the #1 reason students get confused.
